# Code of conduct

This project uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and kind.
- Give and accept helpful feedback.
- Focus on what is best for the community.
- Do not harass, insult or attack people.

Report unacceptable behavior to the maintainer through a private GitHub message to `quark-sri`. The maintainer reviews every report and keeps the reporter's identity private.
