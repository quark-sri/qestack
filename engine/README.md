# qestack engine

The `qestack` command-line tool. It runs the qestack gates: lint, traceability, red-before-green, flakiness, mutation score, seeded faults, guard, locks, scoring and feedback.

- Python 3.11 or later. No other dependencies.
- Install: `pipx install "git+https://github.com/quark-sri/qestack#subdirectory=engine"` (PyPI release later).
- Start: `qestack init`, then `qestack doctor`.
- Help: `qestack --help`.

See the main [README](../README.md) and [docs](../docs/) for the full guide.
